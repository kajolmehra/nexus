# Security and confidentiality

This public case study excludes source documents, knowledge-graph data, API tokens, Firebase project settings, user accounts, form submissions, generated PDFs, and backend URLs. The repository is limited to sanitized narrative content and approved visuals.

Before publishing screenshots, replace document names, entity labels, claimant details, graph text, API hostnames, and account information. Never include `.env` files, service-account JSON, uploaded files, or production exports.
